🚗 LimoGo - Quick Start

Hướng dẫn bắt đầu nhanh với Supabase

📋 Bước 1: Tạo tài khoản Supabase

Trước tiên, bạn cần một tài khoản Supabase để lưu dữ liệu.

  • Truy cập https://supabase.com
  • Click "Sign Up"
  • Chọn cách đăng ký (GitHub, Google hoặc Email)
  • Xác thực email nếu cần
✓ Tip: Dùng Gmail hoặc GitHub sẽ nhanh nhất

🆕 Bước 2: Tạo dự án Supabase

Sau khi đăng nhập, tạo một dự án mới.

  • Click "New project"
  • Điền tên dự án: limogo (hoặc tên khác)
  • Nhập mật khẩu cơ sở dữ liệu (ghi nhớ mật khẩu này)
  • Chọn Region: Singapore (gần VN nhất)
  • Click "Create new project"
  • ⏳ Chờ 5-10 phút cho đến khi hoàn thành
⚠️ Quan trọng: Lưu mật khẩu database ở nơi an toàn!

🔑 Bước 3: Lấy API Keys

Lấy Project URL và Anon Public Key từ Supabase.

  • Trong Supabase Dashboard, click ⚙️ "Project Settings" (góc dưới trái)
  • Click tab "API"
  • Sao chép "Project URL"
    • Trông như: https://xxxxx.supabase.co
  • Sao chép "Anon Public Key"
    • Trông như: eyJhbGci... (rất dài)
⚠️ Cảnh báo bảo mật:
  • ✅ Dùng được: Anon Public Key (safe cho frontend)
  • ❌ Không dùng: Service Role Key (chỉ backend)

⚙️ Bước 4: Cập nhật file cấu hình

Điền API keys vào file js/supabase-config.js

  1. Mở file js/supabase-config.js bằng editor (VS Code, Notepad, v.v.)
  2. Tìm dòng:
    export const SUPABASE_URL = "https://apbkhhmdofljvitwkvcf.supabase.co";
  3. Thay thế bằng Project URL của bạn
  4. Tìm dòng:
    export const SUPABASE_ANON_KEY = "eyJhbGc...";
  5. Thay thế bằng Anon Public Key của bạn
  6. Lưu file (Ctrl+S)
✓ Ví dụ:
export const SUPABASE_URL = "https://your-project.supabase.co"; export const SUPABASE_ANON_KEY = "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...";

💾 Bước 5: Chạy SQL Schema

Tạo bảng database cần thiết.

  • Trong Supabase Dashboard, click "SQL Editor" (bên trái)
  • Click "New Query"
  • Mở file supabase/schema.sql từ thư mục dự án
  • Copy toàn bộ nội dung (Ctrl+A → Ctrl+C)
  • Paste vào SQL Editor (Ctrl+V)
  • Click nút "Run" (hoặc Ctrl+Enter)
  • ⏳ Chờ cho đến khi thấy "Command completed successfully"
✓ Xác thực: Click "Table Editor" → Bạn sẽ thấy các bảng mới:
  • profiles
  • drivers
  • rides
  • payments
  • promo_codes

🚀 Bước 6: Chạy ứng dụng

Khởi động server local để chạy LimoGo.

Cách 1: Dùng Python (Dễ nhất)

cd /đường/dẫn/tới/timenew python -m http.server 8000

Cách 2: Dùng Node.js

cd /đường/dẫn/tới/timenew npx http-server -p 8000

Cách 3: VS Code Live Server

  • Cài extension "Live Server"
  • Chuột phải vào index.html
  • Chọn "Open with Live Server"
✓ Khi chạy thành công: Mở trình duyệt → http://localhost:8000

✅ Bước 7: Kiểm tra kết nối

Đảm bảo Supabase kết nối đúng.

  • Mở Developer Console (F12 → Console tab)
  • Gõ lệnh:
    window.limoGoSupabase.auth.getSession()
  • Nếu không có lỗi = Kết nối OK ✓

📝 Bước 8: Thử chức năng

Kiểm tra các tính năng chính.

  • Trang chủ hiển thị bình thường
  • Click "Đăng nhập" → Hiển thị modal
  • Đăng ký tài khoản mới (Email + Mật khẩu)
  • Đặt xe → Chọn địa điểm → Xác nhận
  • Xem "Ví" → Hiển thị số dư thật
  • Xem "Lịch sử" → Thấy chuyến vừa đặt
  • Xem "Tài khoản" → Hiển thị thông tin đúng
✓ Nếu tất cả OK = LimoGo đã sẵn sàng!
